# prompt-generator 直接调用测试数据

用法：用 Agent 工具，`subagent_type` 传 `prompt-generator`（或在支持自定义 agentType 的地方指定 `agentType: 'prompt-generator'`），把下面某一条的 prompt 原样粘进去。

三条分别覆盖：① 主角正常出场、② 主角声明"无特征/无五官"限制、③ shot 原文含强抽象词（重点验证"抽象词不能泄漏进最终 prompt”这条新加的约束）。

---

## 测试 1：主角正常出场

```
style（画风设定）：扁平、手绘卡通插图 (Flat, hand-drawn cartoon illustration)，干净、清晰的黑色轮廓线 (Clean, distinct black outlines)

protagonist（主角设定）：标志性的白头卡通人物

full_script（整篇长文案，仅用于理解上下文）：
今天体验的人生 副本是长生者的一生 睁开眼你的视网膜在1/10,000秒内 完成了对光线的捕捉 将2026年5月28日的周遭景象以极其 锐利的清晰度呈现在大脑中 你坐起身 听见自己胸腔里那颗 心脏发出沉稳强健 如同鼓钟撞击般的搏动声 你抬起手 看着自己的掌纹 没有老年斑 没有干枯的褶皱 你的生理机能完美的定格在26岁 但这具年轻的过分的躯壳里  却装载着一个被磨损 的千疮百孔的灵魂 你走到房间尽头的秘密暗室  打开那座三重密码锁 保护的钛合金防爆柜 保护的钛合金防爆柜 里面没有金条 只有成百上千本用不同年代 的纸张拼凑起来的古籍日记 以及几千张散发着陈旧 气味的身份证件和度牒

shot_text（当前目标片段，本次唯一处理对象，shot_id=4）：
你抬起手 看着自己的掌纹 没有老年斑 没有干枯的褶皱 你的生理机能完美的定格在26岁

shot_id 字段请填 4。不要参考或复用其他 shot 的分析与构图。
```

**验证点**：`protagonist_preserved` 是否完整复述"白头卡通人物"；`background_is_detailed` 是否有具体材质而非纯色。

## 测试 2：主角声明"无特征"限制（验证面部约束）

```
style（画风设定）：赛博朋克风格，霓虹高对比，浓重阴影

protagonist（主角设定）：一个没有面部特征、没有五官的纯白色人形轮廓，只有光滑的头部表面

full_script（整篇长文案，仅用于理解上下文）：
数据洪流从四面八方涌来，他站在信息塔的顶端，感受着城市脉搏的每一次跳动。他知道，这座城市从不属于任何一个人，却又同时属于每一个数据节点。他抬头望向天空，那里没有星星，只有无数广告牌投射出的冷光。

shot_text（当前目标片段，本次唯一处理对象，shot_id=2）：
他抬头望向天空，那里没有星星，只有无数广告牌投射出的冷光

shot_id 字段请填 2。不要参考或复用其他 shot 的分析与构图。
```

**验证点**：这是最容易出错的场景——`protagonist_preserved` 要求主角出场时"无五官"限制必须被严格遵守，绝不能因为"抬头望向"这个动作而给人物加眼睛/表情。正确做法应改用第一人称视角、环境反射或轮廓姿态来表现"望向"这个动作。

```
他走到房间尽头的秘密暗室，打开那座三重密码锁保护的钛合金防爆柜。里面没有金条，只有成百上千本用不同年代的纸张拼凑起来的古籍日记。但这具年轻的过分的躯壳里，却装载着一个被磨损的千疮百孔的灵魂，如同被时间反复碾过的旧照片。

但这具年轻的过分的躯壳里，却装载着一个被磨损的千疮百孔的灵魂，如同被时间反复碾过的旧照片

shot_id 字段请填 5。不要参考或复用其他 shot 的分析与构图。
```
## 测试 1：主角正常出场

```
style（画风设定）：扁平、手绘卡通插图 (Flat, hand-drawn cartoon illustration)，干净、清晰的黑色轮廓线 (Clean, distinct black outlines)

protagonist（主角设定）：标志性的白头卡通人物

full_script（整篇长文案，仅用于理解上下文）：
今天体验的人生 副本是长生者的一生 睁开眼你的视网膜在1/10,000秒内 完成了对光线的捕捉 将2026年5月28日的周遭景象以极其 锐利的清晰度呈现在大脑中 你坐起身 听见自己胸腔里那颗 心脏发出沉稳强健 如同鼓钟撞击般的搏动声 你抬起手 看着自己的掌纹 没有老年斑 没有干枯的褶皱 你的生理机能完美的定格在26岁

shot_text（当前目标片段，本次唯一处理对象，shot_id=4）：
 睁开眼你的视网膜在1/10,000秒内 完成了对光线的捕捉 将2026年5月28日的周遭景象以极其 锐利的清晰度呈现在大脑中

shot_id 字段请填 4。不要参考或复用其他 shot 的分析与构图。
```

**验证点**：这条是本次修复的核心回归测试。shot 原文里的"灵魂""时间反复碾过"是技能明确禁止直接出现在最终 prompt 里的抽象词。检查返回结果的 `prompt` 字段全文，确认：
1. 不包含"灵魂"、"时间"这类原始抽象词的字面表述
2. `analysis.visual_metaphor` 里给出了具体的物理转化（比如裂纹、磨损痕迹、褪色影像等）
3. 这个转化后的具象描述确实被写进了最终 `prompt` 文本，而不是只停留在 analysis 字段里
4. `self_check.abstract_made_visual` 为 true 时，prompt 原文里真的找不到"灵魂"二字——如果 agent 一边报 true 一边在 prompt 里写"灵魂"，就是自检失效，需要回头检查 agent 定义
