# 叙事插画提示词生成标准流程

本技能用于将文学叙事片段转化为 AI 绘图可识别的标准提示词，统一风格与主角识别度，适用于系列插画创作。

**使用前必须传入的四个参数**：
1. **大美术品类（art_style）**：全系列统一的视觉基底
2. **主角统一锚点（protagonist_anchor）**：含视觉锚点 + 气质锚点，保证跨场景识别；若该系列无固定主角则传 null
3. **当前分镜片段（current_shot）**：本次需要生成提示词的具体片段内容
4. **全部文案上下文（full_context）**：完整文案或至少包含该片段前后文的上下文，用于判断片段在整体叙事中的位置、主角所处阶段、前后场景关联等

---

## 一、前置准备：全系列统一基准（使用前传入，所有片段复用）

这部分是系列创作的基础，**使用本技能前必须传入**，不需要每次换片段调整，提前设定即可解决「风格混乱、主角识别度低」的问题。

### 1. 大美术品类（全系列视觉基底，权重最高）【需传入】

定调全系列的基础绘制规则，由调用方自定义传入。格式要求：包含风格品类 + 绘制逻辑 + 排除项。

**传入示例**（2D 扁平手绘卡通风）：
> **2D 扁平手绘卡通风格插画，统一采用清晰黑色轮廓线 + 平涂上色的绘制逻辑，无写实纹理、无 3D 渲染效果、无多余文字水印。**

**其他可自定义方向**：国风工笔插画、日系赛璐璐动画风、美式复古漫画风、水彩插画、像素风等。

### 2. 主角统一锚点（跨场景识别核心）【需传入】

不需要固定主角的所有外形，仅保留核心锚点，服装、发型可随场景时代适配，保证系列统一性。由调用方自定义传入。

**传入格式**：
- **视觉锚点**：头部特征 + 面部风格 + 身形比例 + 不同场景/时代的外形适配规则
- **气质锚点**：随内容/阶段动态适配的情绪气质谱系

**传入示例**（永生者主角）：

> **视觉锚点**：全系列主角采用 **2.5 头身 Q 版极简卡通比例**，面部仅用黑点做眼睛、短线做嘴，无多余五官细节；外形随时代适配：
> - 古代场景：白色圆形光头、穿对应朝代服饰
> - 现代场景：利落黑色短发、穿对应时代服装
> - 未来场景：适配未来感的极简造型
>
> **气质锚点**：随内容适配：
> 恣意、狂喜、对世界充满新鲜感，痛苦、绝望、恐惧，麻木、疏离、抽离，永远和周遭环境有割裂感等等等。

### 3. 提示词通用权重规则（适配所有 AI 绘图模型）

所有提示词严格按照 **「风格定调 → 核心主体 → 分层场景 → 光影色彩 → 氛围总结」** 的顺序撰写，越靠前的内容 AI 识别权重越高，从根源上避免画面跑偏。

## 二、单条目标片段转化标准流程（每处理 1 条片段走 1 次，可复用）

这是文学语言转译为 AI 视觉语言的核心步骤，每一步都对应从「抽象叙事」到「具象画面」的转化逻辑。

### 步骤 1：片段核心信息解码（转译基础）

拿到目标片段后，结合全部文案上下文，逐字拆解 3 类信息，把所有抽象文学描述转化为可视觉化的内容。

**首要判断：本片段是否有主角出场？**
- 结合上下文判断当前分镜是否为主角在场的场景
- 若有主角：按以下 ② 提取主角状态，主角是画面核心
- 若无主角：跳过 ②，画面以场景/环境/配角为核心，提示词结构中「核心主体」部分替换为「画面核心主体（场景/配角/物品等）」

| 拆解维度 | 操作方法 | 逻辑说明 |
|---------|---------|---------|
| ① 核心情绪 + 题材标签 | 先判断片段的核心情绪（狂喜 / 痛苦 / 麻木 / 恐怖 / 苍凉 / 紧张等），再定题材属性（古代战争 / 江南古风 / 现代都市 / 赛博未来 / 暗黑恐怖 / 抽象心理等） | 这一步是「构图选择」和「光影氛围」的匹配依据：情绪决定光影色调与氛围，题材决定场景元素与构图方式 |
| ② 主角当下状态（有主角时必填） | 从文案中精准提取主角的动作姿态（站立 / 躺倒 / 奔跑 / 中箭 / 跪地等）、神态表情（狂喜 / 痛苦 / 呆滞 / 坏笑 / 面无表情等）、外形状态（受伤 / 复活 / 服装 / 身体特效等）。**需结合全部上下文判断主角当前处于哪个气质阶段**，确保神态匹配 | 主角是叙事核心，不能凭空创作：比如「被三枚羽箭钉在城墙」片段，主角状态就是「背靠城墙、胸口贯箭、痛苦嘶吼」；「获得能力百年感谢上苍」片段，主角状态就是「跪地高举双臂、狂喜大笑」 |
| ③ 具象元素提取 + 抽象修辞转译 | 首先列出文案中所有可直接看见的具象物品；再把比喻、抽象描述转化为可视的实体符号（AI 无法理解抽象修辞，必须落地为画面元素）；最后按「前景（离观众最近）→中景（画面核心周围）→背景（最远环境）」给所有元素分层 | ① 具象元素不能遗漏关键意象：比如乱葬岗片段的「白骨、肉芽、血管、月光、战旗、乌鸦、满月」，围城战片段的「残破城墙、火焰、浓烟」，全部纳入场景；② 抽象修辞必须转译：比如「爱人是短暂车票」转译为「被撕成两半的旧车票，印着亲人头像打红叉」；「特修斯之船记忆被替换」转译为「主角身体是半透明拼图块，印着记忆碎片不断掉落」；「大脑过载」转译为「半透明头颅里装满公式乱码，闪电从脑中炸开」 |

### 步骤 2：匹配构图规范（情绪传递核心）

根据步骤 1 的解码结果，选定适配的构图形式，直接决定画面的情绪匹配度。

> 注：风格统一由传入的大美术品类保证，不需要额外的细分质感。情绪和题材通过「光影色彩 + 场景元素 + 构图」来传递。

**构图匹配规则**（构图本身就是无声的情绪语言）：

| 场景类型 | 构图选择 | 效果 |
|---------|---------|------|
| 宏大开阔 / 荒凉孤独 / 战争动态 | 横向宽幅构图 | 体现空间感与动态感 |
| 压迫感强 / 主体特写 / 冲击性 | 中心构图 / 近大远小纵深透视构图 | 强化主体冲击力 |
| 静态凝滞 / 麻木疏离 / 对称场景 | 对称构图 / 一点透视构图 | 传递停滞、压抑感 |
| 紧张追逐 / 混乱冲突 | 斜向动态线构图 | 强化紧张慌乱感 |

### 步骤 3：按权重顺序撰写提示词（AI 可识别的标准格式）

严格按照权重从高到低撰写，所有描述要具体，避免「好看的颜色」「很多人」这类模糊词汇。

#### 第一部分（最高权重）：风格定调

**格式**：【传入的大美术品类】+【构图形式】

> 注：绘制基础（轮廓线、上色方式等）已包含在传入的大美术品类中，无需重复添加。

**示例**（乱葬岗复活片段，大美术品类为 2D 扁平手绘卡通风）：
> 2D 扁平手绘卡通插画，粗黑清晰轮廓线，平涂上色，横版宽幅构图。

#### 第二部分（次高权重）：核心主体

**有主角时**：
**格式**：【传入的主角视觉锚点】+【动作姿态】+【神态表情（匹配气质锚点阶段）】+【服装/状态特效（伤口、发光、拼图等）】

**示例**（乱葬岗复活片段）：
> 画面中心是一具半腐烂的卡通人形躯体，仰面躺倒在尸骸堆中：头部为标志性白色圆形卡通脸，脸部下半边缘不规则破碎开裂、带有细碎裂纹，露出内部暗黑色基底；脸上是呆滞惊愕的神情，两个小圆黑点眼睛，嘴巴微张呈困惑惊恐状。躯体皮肉呈暗灰黑色、残破不堪，胸腔处露出完整的白色肋骨骨架，全身上下缠绕密布着发光的亮红色血管脉络，红光微微晕染在周围暗色皮肉上，双臂向两侧自然摊开。

**无主角时**：
**格式**：【画面核心主体是什么（场景/配角/物品等）】+【主体的形态、姿态、状态细节】
> 原则：无主角的画面必须有明确的视觉重心，不能是散乱的空镜头；核心主体可以是一处关键场景、一个重要配角、一件标志性物品。

#### 第三部分（中权重）：分层场景元素

**格式**：按「前景→中景→背景」顺序描述，每个元素写清楚位置、形态、颜色，放入步骤 1 拆解的所有具象元素、转译的修辞符号。
> 有主角时，中景围绕主角展开；无主角时，中景围绕画面核心主体展开。

**示例**（乱葬岗复活片段）：
> 场景为月夜下的古战场尸山废墟：
> - 前景：左下角可见粉红色的血肉脑组织残块；
> - 中景：地面堆满散落的白骨、断裂的木梁、残破的盔甲残片；左上方竖立着一杆破损的黑色战旗，旗面撕裂、带有破洞；画面左右高处各站立一只黑色乌鸦；
> - 背景：右上角的灰蒙夜空中悬挂一轮明亮的灰白色满月；远处是灰暗朦胧的低矮山丘轮廓。

#### 第四部分（次中权重）：光影与色彩定调

**格式**：【整体主色调】+【光源位置与类型（月光/火光/冷光/霓虹等）】+【色彩/明暗对比效果】+【氛围总结】

**示例**（乱葬岗复活片段）：
> 整体以冷灰暗黑色调为主，月光为唯一冷光源，亮红色血管与暗色环境形成强烈视觉对比，氛围阴森诡异、荒凉死寂。

#### 第五部分（低权重，可选）：反向排除词

根据传入的大美术品类和主角锚点灵活调整。以下为 2D 扁平手绘卡通风的统一排除词示例：
> 无 3D 效果，无写实纹理，无多余文字水印。

### 步骤 4：校验调整

写完后对照原文和上下文检查：
1. 关键意象有没有遗漏？
2. 本片段是否有主角？判断是否符合上下文？
3. 有主角时：主角状态是否符合文案？气质阶段是否匹配上下文位置？
4. 无主角时：画面是否有明确视觉重心？是否有不该出现的主角？
5. 构图是否匹配片段情绪？
6. 有没有 AI 无法识别的模糊词汇？

调整后即可得到最终提示词。

## 三、完整转化演示（原文案片段全流程验证）

**本演示使用的传入参数**：
- **大美术品类**：2D 扁平手绘卡通风格插画，清晰黑色轮廓线 + 平涂上色，无写实纹理、无 3D 渲染效果、无多余文字水印
- **主角锚点**：2.5 头身 Q 版极简卡通比例，黑点眼、短线嘴；古代白色圆形光头，现代利落黑色短发，未来极简造型；气质随内容适配（初期恣意/中期痛苦/后期麻木）

### ▶ 目标片段

> 「你曾白衣折扇，走过烟雨江南的秦淮河畔；也曾一马一剑，在漫天黄沙中和匈奴的铁骑擦肩而过。」

（选自原文永生初期段落）

### 步骤 1：信息解码

- **情绪 & 题材**：情绪是意气风发、潇洒恣意，属于古风跨场景叙事题材；
- **主角状态**：永生初期的鲜活状态，两种身份融合：一侧是白衣持扇的江南文人，神态轻松带笑；一侧是胡服佩剑的塞外骑手，神态锐利，骑马与骑兵错身；
- **元素分层**：
  - 前景：柳丝、青石板水渍、黄沙、断箭
  - 中景：秦淮河画舫、撑伞行人、匈奴铁骑、战马
  - 背景：江南黛瓦民居、雾中远山、戈壁沙丘、落日
  - 无抽象修辞，采用场景自然渐变表现跨时空经历。

### 步骤 2：匹配构图

- **构图**：横向宽幅构图，场景从左到右渐变过渡，中心聚焦主角。

### 步骤 3：生成最终提示词

> 2D 扁平手绘卡通风格插画，清晰黑色轮廓线，平涂上色，横向宽幅构图。
>
> 画面视觉中心为标志性白色圆形光头卡通主角，画面自然衔接两种状态：左侧主角身着月白色交领宽袖长衫，手持半开的墨竹折扇，衣摆被微风拂起，神态轻松洒脱、眼角带笑；右侧主角身着玄色窄袖胡服劲装，腰悬长剑，骑在黑色战马上，身体微侧避让擦身而过的匈奴骑兵，神态锐利恣意、意气风发。
>
> 场景从左到右从江南过渡到塞外：
> - 前景：左侧前景是垂落的嫩绿柳丝、被雨打湿的青石板路水渍；右侧前景是被风卷起的黄沙尘粒、半埋在沙里的断箭残片；
> - 中景：左侧中景是秦淮河面的朦胧水雾，河上漂着挂竹帘的乌篷画舫，岸边有撑淡粉色油纸伞的行人背影；右侧中景是扬着鬃毛的匈奴铁骑队列，骑兵身着皮甲举着狼头旗帜，马蹄扬起漫天黄尘；
> - 背景：左侧背景是烟雨中朦胧的青灰黛瓦江南民居，远山如黛笼罩在薄雾里；右侧背景是昏黄落日下的连绵戈壁沙丘，天空被黄沙晕染成暖赭色。
>
> 整体色调从左侧的冷青灰烟雨色调自然过渡到右侧的暖赭黄沙色调，左侧是阴天柔和漫射光，右侧是落日暖侧光，光影柔和自然，氛围潇洒开阔，带着时光错落的恣意感。
>
> 无 3D 效果，无写实纹理，无多余文字水印。

### 校验

所有元素来自原文，主角状态符合传入的气质锚点（初期恣意），构图适配古风跨场景叙事，与传入的大美术品类风格完全统一。

## 四、抽象修辞转译速查表

常见抽象概念的视觉化转译参考：

| 抽象概念 / 修辞 | 视觉转译方案 |
|----------------|-------------|
| 「爱人是短暂车票」 | 被撕成两半的旧车票，印着亲人头像打红叉 |
| 「特修斯之船 / 记忆被替换」 | 主角身体是半透明拼图块，印着记忆碎片不断掉落 |
| 「大脑过载」 | 半透明头颅里装满公式乱码，闪电从脑中炸开 |
| 「时间流逝」 | 倾斜的沙漏、流动的时钟指针、层层叠叠的日历页 |
| 「孤独 / 疏离」 | 主角周围有一圈空白/透明气泡，与环境格格不入 |
| 「永生 / 轮回」 | 首尾相接的蛇（衔尾蛇）、圆形循环的路径 |
| 「痛苦 / 挣扎」 | 黑色荆棘缠绕身体、裂缝从身体向外蔓延 |
| 「麻木 / 空洞」 | 胸口空缺一块、身体呈半透明灰白色 |
| 「新生 / 复活」 | 发光的血管脉络、嫩芽从废墟中破土 |
| 「记忆碎片」 | 漂浮的半透明照片/拼图块，逐渐消散 |

## 五、快速检查清单（生成后必过）

- [ ] 风格定调是否放在最开头？
- [ ] 本片段是否有主角？判断是否正确？
- [ ] 有主角时：是否使用了传入的视觉锚点？气质是否匹配对应阶段？
- [ ] 无主角时：画面是否有明确的视觉重心（核心场景/配角/物品）？
