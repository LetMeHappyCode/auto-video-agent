# Narrative Illustration Prompt

将长文案中的一个目标片段，转化为高具象度、富有视觉隐喻和空间层次感的高质量 AI 插画提示词（Prompt），可直接交给其他图像生成模型使用的单段插画提示词。严格执行本技能的输入收集、五步法和交付格式。
本技能旨在将给定的长文案切片（分镜语义块）翻译为高具象度、富有视觉隐喻和空间层次感的高质量 AI 插画提示词（Prompt）。技能具备智能主角判断能力，能够动态选择是否引入【主角设定】**，并严格融合**【画风设定】进行标准化输出。

## 📥 输入参数 (Input Variables)

在使用本技能时，系统或用户需提供以下 4 项上下文参数：

```yaml
1. 画风设定: "<在此填入全局自定义画风，如：3D render, Pixar style, Cinematic lighting...>"
2. 主角设定: "<在此填入自定义主角的具体外观描述，如：一个穿着黄色雨衣、戴着红框眼镜的8岁小女孩...>"
3. 整篇长文案（上下文）: "<在此填入完整的故事文案，用于让AI理解前因后果与情感基调...>"
4. 当前目标片段: "<在此填入当前需要生成插画的具体分镜文案/语义块...>"

```
每次执行前确认已取得以下四项。缺少哪项，只追问缺失项；不要使用默认值推断。


## ⚙️ 核心底层逻辑与四大硬性约束

### 1. 主角识别与调用逻辑（强约束）

* **上下文研读**：结合**整篇长文案（上下文）**深入理解故事背景，再重点分析**当前目标片段**。
* **存在性判定**：并非每个分镜都需要主角。
* **有主角场景**：若目标片段涉及主角的动作、情绪、主观视角体验或直接出场，必须调用**主角设定**，并将其置于画面视觉中心或关键构图点。
* **无主角场景**：若目标片段描述的是宏观环境、景物特写、静物隐喻或无人空镜头，严禁强行插入主角，应将视觉焦点转移至环境主体或道具上。

### 2. 全局画风融合（模块化约束）

* 严格遵循**画风设定**的关键词或风格描述。
* 画风词需有机嵌入到提示词的开头与整体描述中，同时配合具体的实体（Object）、光影（Lighting）和构图（Composition），避免纯堆砌无意义的虚词。

### 3. 抽象文案的“视觉隐喻落地”（具象化约束）

面对“灵魂”、“绝望”、“时间的流逝”、“完美的生理机能”等抽象或文学化词汇，**严禁直接在提示词中使用抽象词**，必须将其转化为物理实体、物理状态或视觉符号：

* **有主角时**：作用于主角本身（如：皮肤上的物理裂纹、胸口散发的虚幻烟雾、受重力撕扯的衣角）。
* **无主角时**：作用于环境或道具（如：剥落的建筑残骸、风化的石化时钟、漂浮的能量粒子）。

### 4. 空间深度与环境细节（拒绝单色背景）

* **严禁出现**“纯黑背景”、“纯白背景”或无细节的单色平涂。
* 即使在需要表现暗淡、孤独或虚无的场景中，也必须填充物理材质、环境细节或光影渐变（如：弥漫的发光微粒、斑驳的锈迹墙面、具有深邃透视感的几何网格、错落的前景剪影）。

### 5. 禁止面部微特征描写（表情控制约束）
* 严禁堆砌面部生理细节：严禁在提示词中加入如“皮肤纹理干净细腻”、“没有任何皱纹或斑点”、“睫毛根根分明”等对面部皮肤或微观特征的描述。

* 允许贴合剧情的情感表情：可根据上下文剧情与情绪走向，适当加入主角的情感表情与神态描述（如：凝重的神情、微张的嘴唇、充满警惕的眼神）。

## 🔄 详细执行步骤（五步公式化流程）

### 步骤 1：上下文分析与主角存在性判定

  1. 读取**整篇长文案（上下文）**，把握当前剧情节点在整篇文章中的情感走向与视觉前后连贯性。
  2. 剖析**当前目标片段**，执行布尔判断：
  * `HAS_PROTAGONIST = True`（需主角）：提取主角的动作、姿态、情绪表情（避开面部细节描写）。
  * `HAS_PROTAGONIST = False`（无主角）：提取环境主体/静态道具（如：一座耸立的铁门、停滞的机械表）。

  3. 提取当前片段的核心道具与情感基调（如：压抑、震撼、迷茫、温馨）。

### 步骤 2：构建“超现实视觉隐喻”（处理抽象文案）
  * **转化公式：** `抽象文字描述 ➔ 物理状态 / 具象符号/ 动态变化 / 视觉符号`
    * **示例 1（有主角 - “绝望吞噬了理智”）**：主角跪倒在地，黑色如墨汁般的粘稠液体从地面裂缝中涌出，顺着主角的双腿向上蔓延爬升。
    * **示例 2（无主角 - “文明的陨落”）**：画面中央是一座半埋在沙丘中的巨大高科技齿轮，齿轮边缘布满绿色苔藓与锈斑，细沙不断从齿缝中滑落。
    * **示例 3（有主角 - “灵魂被磨损得千疮百孔”）**：主角身体表面“布满黑色碎裂纹路，胸口和四肢有多处破损和剥落的痕迹，有白色的气流或烟雾向后飘散。
    * **示例 4（有主角 - “心跳如鼓钟撞击”）**：主角的胸口处直接安置“一个正在发出金色震动波纹的古代铜钟”。

### 步骤 3：设计环境光影与光影渐变（奠定情绪与空间感）
  设计画面背景，赋予其空间层次感：
  举例：
  * **暗色/孤独基调**：“深灰色的黑暗空间，空气中悬浮着极细小的金色发光微粒，背景是带有斑驳锈迹与大头螺丝的金属墙面。”
  * **科技/虚幻基调**：“背景为向远方无限延伸的蓝色数字矩阵，伴有高光的线条穿梭在深邃的透视线条中。”

### 步骤 4：设计镜头构图与视角张力
  指定透视与视角，增强视觉冲击力：
  有主角的场景：避免极近景、特写类似的镜头。
  举例：
    * **宏大/渺小对比/无力感**： 超广角 / 仰视角 / 俯视角/远景超现实主义构图。
    如：（主体横亘在半空中，身下是密密麻麻排列着高楼大厦的微缩现代城市景观。） 如：（从高空鸟瞰，主角或核心道具位于巨大阴影的边缘）。
    * **神秘/剧情张力**： 框架构图 / 倾斜构图。
    如：（从一个狭窄的灰色密室内部向外看，大门刚刚被推开，两侧整齐或倾斜地堆放着层叠的古旧书籍）。


### 步骤 5：提示词分流组装与输出

根据步骤 1 的判定结果，严格按照以下输出模板拼装最终提示词。提示词用中文输出。

---

> * **画面主体与道具**：[描述关键道具与视觉符号]

> * **画面焦点主体**：[描述环境主体或核心道具]

## 交付格式

除非用户明确只要最终 Prompt，否则严格使用以下工作表：

```markdown
* **是否有主角：** 有 或 无
* **【当前目标片段】：** <用户给出的目标片段>
* **Step 1 三要素提取与判定：** 主体：<判定 + 动作描述> | 道具：<核心道具> | 情绪：<核心情感基调>
* **Step 2 视觉隐喻转化：** <抽象词> ➔ <具体的物理状态 / 具象符号描述>
* **Step 3 & 4 构图与背景设计（已应用非纯色约束）：** 构图：<构图与透视说明> | 背景：<富有材质、细节或渐变的光影背景描述>
* **Step 5 光影与色彩设计：** <具体的光影方向、色彩和光源类型>
* **📌 标准交付 Prompt：**
  > <一段连续流畅的提示词>
```

## 异常处理与修改

- 缺少画风或主角设定时，各追问一次；不要虚构。
